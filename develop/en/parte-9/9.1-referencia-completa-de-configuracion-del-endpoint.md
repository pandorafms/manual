# Full EndPoint configuration reference

> Raw technical reference for `pandora_agent.conf`: every general token and
> every module token, with its compatibility by EndPoint (Go, Perl, Windows).
> It is looked up, not read from cover to cover. The explanations and the
> examples are in
> [2.1 · Monitoring with EndPoints](../parte-2/2.1-monitorizacion-con-endpoints.md),
> which this page links to.

## Introduction

This reference gathers, table by table, every `pandora_agent.conf` token
recognised by the three Pandora FMS EndPoints: the Go EndPoint, the Perl
EndPoint (Linux/Unix) and the Windows EndPoint. For each token it states its
description, its syntax or default value, and whether the Go EndPoint, the Perl
EndPoint and the Windows EndPoint accept it.

`pandora_agent.conf` is located in:

| EndPoint | Path |
|---|---|
| Go and Perl (Linux/Unix) | `/etc/pandora/pandora_agent.conf`. Both use the same file at the same path. With an installation in a custom path, the configuration stays in `<prefix>/etc/pandora/`; on FreeBSD and NetBSD, the installer already uses `/usr/local/etc/pandora`. |
| Windows | `C:\Program Files\pandora_agent\pandora_agent.conf` |

The file syntax is the same in the three EndPoints: one token per line, comments
with `#`, and module tokens grouped in `module_begin` / `module_end` blocks
(except `module_plugin`, which can also go loose on a single line, outside any
block). General tokens are valid anywhere in the file, outside a module block.

For explanations, examples and the reason behind each token, see
[2.1 · Monitoring with EndPoints](../parte-2/2.1-monitorizacion-con-endpoints.md).

## Notable differences between EndPoints

- **Default XML encoding.** Perl and Go use `UTF-8`; Windows uses
  `ISO-8859-1` (see `encoding`).
- **A different name for the same concept.** The start-up delay is called
  `delayed_startup` in Perl and Go, and `startup_delay` on Windows.
- **Token alias.** `module_service` is an exact alias of `module_proc` on Unix
  (same process check); on Windows they are different built-ins (process vs.
  service), with watchdogs that behave differently.
- **Asymmetric watchdog.** The Windows watchdog exists only for `module_proc`
  (it needs `module_start_command`, `module_retries`, `module_startdelay`,
  `module_retrydelay`, `module_user_session`) and for `module_service` (it
  restarts the service itself, without a recovery command). Neither Perl nor Go
  implements a watchdog.
- **Asynchronous module only on Windows.** `module_async` exists only in the
  Windows EndPoint; Perl and Go derive the asynchronous type automatically when
  a module with `module_absoluteinterval` runs `once`.
- **Tokens with a variable name.** `module_macro<name>` (module macros) and
  `custom_field<n>_name` / `custom_field<n>_value` are accepted by the three
  EndPoints; the general macros `macro<name>`, only by Perl and Go.
- **UDP server.** It exists only in Perl and Windows (not in Go). The format of
  the orders differs: Perl accepts `START PROCESS <name>` /
  `STOP PROCESS <name>`; Windows requires exactly three words
  (`<order> <action> <target>`, for example `REFRESH AGENT *`,
  `START PROCESS <name>`, `START SERVICE <name>`), and it adds the control of
  services (`service_<name>`) that Perl does not have.
- **Remote configuration and transport.** The Go EndPoint accepts only
  `remote_config` with `transfer_mode` `tentacle` or `local`; Perl accepts it
  with any transfer mode.
- **Windows-only tokens.** All the built-in Windows query modules
  (`module_wmiquery`, `module_perfcounter`, `module_snmpget`, `module_ping`,
  `module_tcpcheck`, `module_logevent`/`module_logchannel` and their filters,
  `module_inventory`, `module_exec_powershell`), in addition to
  `disable_logfile`, `default_native_encoding`, `startup_delay` and
  `udp_server_address`.
- **Unix-only tokens (Perl and Go).** `module_cpuproc`, `module_memproc`,
  `module_occupiedpercentdisk`, `module_proc_cmd`, `module_freedisk_cmd`,
  `pandora_user`, `logfile`/`logsize`/`logrotate`, `cron_mode`,
  `agent_threads`, `cmd_file`, `include`, `timezone_offset`, `pandora_nice`,
  `transfer_mode_user` and `server_path_conf` / `server_path_md5` /
  `server_path_zip`.
- **Token only parsed, with no equivalent in the other two.** `server_path_ref`
  exists only in the Perl EndPoint (reference directory of the remote
  configuration).
