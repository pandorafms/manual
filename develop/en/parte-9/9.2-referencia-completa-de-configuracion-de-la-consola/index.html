    Full console configuration reference¶

    This reference is not read from cover to cover: it is looked up by option name or by tab, like a dictionary. It gathers the whole configuration of the Web console (node and Command Center) and of include/config.php, so that any other chapter can link here instead of repeating a table of options.

    Where each thing lives:

    • Web console (Settings → System Settings). Almost all the configuration of behavior, appearance and credentials of external services. It is stored in the database, not in a file: it changes on the fly, without restarting anything.
    • include/config.php. A handful of values that are edited by hand only, before the console can connect to the database: database connection, installation path, encryption passphrase. See § 23.
    • Command Center. A special console that centralizes several nodes. It has its own configuration pages (§ 22) and, in addition, it can set some settings of the nodes it manages centrally.

    A node with "centralized management" active in a specific section stops accepting local changes in that section: they are edited from the Command Center and synchronized to the node.

    22.3 What is synchronized from the node by the Command Center¶

    "Centralized management" allows the Command Center to write the configuration of a node, in addition to policies, advanced ACL and components, in a synchronized way: the affected section of the node stops accepting local changes while the centralized management is active (see the introduction to this chapter). The exact detail of which sections are synchronizable is not verified as of this writing; it will be expanded in a later revision of this chapter.
