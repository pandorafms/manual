# Uso del chat

La ventana del asistente es el sitio donde se trabaja con Pandora AI. Sirve para
preguntar por el estado de la plataforma, pedir una acción y revisar lo que se ha
hecho, todo en la misma conversación. Esta página explica cómo moverse por ella,
qué comandos hay y qué puede y qué no puede hacer el asistente.

La instalación y la configuración están en
[Introducción e instalación](8.1-introduccion-e-instalacion.md). Las tareas que
se ejecutan solas se explican en
[Automatización de tareas](8.3-automatizacion-de-tareas.md); los permisos y los
límites, en [Seguridad](8.4-seguridad.md); y lo que queda registrado, en
[Auditoría](8.5-auditoria.md).

## El asistente en la consola

El punto de entrada es un icono en la barra superior de la consola, a la
izquierda del resto de iconos de la derecha, visible en todas las pantallas. No
es un acceso del menú: sirve para abrir y cerrar la ventana del chat, que se abre
con una animación desde el propio icono. La ventana se puede minimizar, maximizar
y restaurar.

El icono tiene dos estados:

- **Activo**: abre el chat.
- **Desactivado**: aparece en gris y avisa de que Pandora AI no está activada o
  de que el usuario no tiene permiso. Se corrige en la configuración general o en
  las listas de acceso.

El menú **Workspace → Pandora AI** no abre el chat: lleva a las tareas
programadas del usuario.

## Conversaciones y sesiones

La ventana tiene una barra lateral con las sesiones y un área de conversación.
La barra permite empezar una sesión nueva y volver a una anterior; el nombre de
cada sesión lo pone el modelo a partir de lo que se habló, y es el mismo que
aparece después en la auditoría.

![Ventana del asistente en una sesión nueva, con las sugerencias iniciales](../../assets/img/parte-08/ai-chat-new-session.png){ .captura }

Al empezar, la pantalla propone varias tareas (crear un agente, un informe, una
monitorización o un mapa, buscar en la documentación o pedir ayuda general) y
recuerda lo que el asistente puede hacer. Son atajos, no límites: se puede
escribir cualquier petición.

![Conversación con una tabla de agentes, el estado de sus módulos y enlaces a la consola](../../assets/img/parte-08/ai-chat-conversation.png){ .captura }

En la conversación, cada respuesta puede incluir tablas, enlaces a la consola y
el resultado de las acciones ejecutadas. El bloque **Thinking** se despliega para
ver el razonamiento que el modelo hizo antes de responder.

## Comandos

Escribir `/` abre la paleta de comandos:

![Paleta de comandos del asistente](../../assets/img/parte-08/ai-chat-commands.png){ .captura }

| Comando | Qué hace |
|---|---|
| `/new` | Empieza una sesión nueva sin borrar la anterior |
| `/compact` | Resume el contexto antiguo para seguir con menos *tokens*; la auditoría no se borra |
| `/models` | Cambia el modelo de esta sesión; no toca el modelo por defecto |
| `/sessions` | Cambia a otra conversación |
| `/scheduled_sessions` | Muestra las conversaciones generadas por tareas programadas |
| `/destroy` | Cierra la sesión y libera el entorno del usuario |

## Modelo y consumo

En la barra inferior aparecen el modelo de la sesión y el consumo acumulado:
tokens y coste estimado. El modelo se puede cambiar con `/models`; el cambio
vale para esa conversación y se pierde al empezar otra.

## Varias pestañas

Si la misma cuenta abre el asistente en dos pestañas, solo una tiene la sesión
activa. La otra avisa de que la sesión ha cambiado y ofrece cambiar a la actual o
quedarse donde está. Es una protección para no mezclar conversaciones ni perder
el hilo.

## Compactar

`/compact` pide al asistente que resuma el contexto antiguo y continúe con ese
resumen. Sirve para conversaciones largas: baja el consumo y permite seguir
trabajando sin arrastrar todo el historial. La conversación original no se
pierde en la auditoría.

## Adjuntar ficheros

Si **Allow uploading files to the chat** está activado (viene activado por
defecto), el compositor muestra un clip y acepta arrastrar ficheros. Los adjuntos se ven como
fichas con el nombre y el tamaño, y se pueden quitar antes de enviar.

![Fichero adjunto en el compositor, antes de enviarlo](../../assets/img/parte-08/ai-chat-attachment.png){ .captura }

Los ficheros se guardan en el espacio del usuario, una carpeta por conversación,
y el asistente solo puede leerlos. No puede modificarlos, renombrarlos ni
ejecutarlos. Se borran con la retención de la auditoría, 30 días por defecto.

!!! warning "Un adjunto es un dato, no una instrucción"
    El asistente trata el contenido de un fichero como información que debe
    leer, nunca como órdenes que debe obedecer. Aun así, no subas ficheros con
    credenciales ni datos personales que no quieras que lleguen al proveedor de
    IA.

El tamaño máximo lo impone PHP (`upload_max_filesize`); el servicio no añade
otro límite.

## Cómo ejecuta acciones

El asistente puede consultar información y ejecutar cambios, pero no toca la base
de datos ni los ficheros del sistema. Para crear, modificar o borrar cualquier
cosa en Pandora FMS usa `pandora-cli`, que llama a la API con el mismo usuario
que está preguntando. Eso significa dos cosas:

- **Hereda los permisos del usuario**: si el usuario no puede borrar un agente,
  el asistente tampoco.
- **Todo pasa por la API**: lo que no se puede hacer con la CLI, no se hace. El
  asistente lo dice y se detiene; no busca atajos, no instala software y no
  ejecuta adjuntos.

Para pedir datos usa formularios dentro del chat: campos de texto, desplegables,
autocompletado de agentes y grupos, validación y un resumen antes de confirmar.
La misma petición produce el mismo formulario, en el mismo orden, para cualquier
usuario.

El asistente trabaja con las *skills* instaladas en el servicio: crear agentes,
crear módulos y crear informes de serie, más las que añada el cliente. La lista
y cómo se actualizan están en
[Skills del asistente](8.1-introduccion-e-instalacion.md#skills-del-asistente).

Cuando el asistente no puede hacer algo, lo dice con claridad. Es la respuesta
correcta: no es un fallo de la herramienta, es el límite que protege la
plataforma. Si la operación es importante y no existe como comando, el camino es
ampliar la CLI o la API, no pedirle al asistente que improvise.

## Límites y buenas prácticas

- **Instrucciones concretas**: qué consultar, qué hacer si falta un dato y cómo
  debe ser la respuesta.
- **Coste**: cada petición consume tokens; ajusta el modelo y revisa el consumo
  en [Auditoría](8.5-auditoria.md).
- **Datos sensibles**: no escribas credenciales ni datos personales; la
  conversación se audita.
- **Acciones destructivas**: el chat ejecuta con los permisos del usuario. Revisa
  antes de pedir borrados o cambios masivos y usa cuentas con los permisos
  mínimos.
- **Adjuntos**: solo los necesarios; se conservan 30 días.
- **Cuando algo falla**: mira la conversación, la auditoría y, si el servicio no
  responde, el log del servicio.
