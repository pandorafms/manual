    SiemEvents¶

    Read authorized SIEM events from nodes

    POST /siem/event/aggregate¶

    Count authorized SIEM events by one dimension

    Exact top-N by count descending, key ascending (numeric for rule/severity). Same resource filters, UTC interval and ACL as listing; last 24h by default. Metaconsole requires one explicit serverId in the body. No paging, custom sort or multi-node merge. Decoder is multivalued: bucket counts may sum above totalEvents. Missing values are counted separately. At most 10000 distinct groups are supported; incomplete bucket coverage fails as 503, never approximate success. truncated only reports groups omitted by the requested top-N; returned counts stay exact.

    GET /siem/event/{idEvent}¶

    Get one authorized SIEM event

    Search retained event indices on the selected node without the list's default date range. Returns the same complete SiemEvent projection as the list, with literal log and dynamic fields. Missing and non-visible IDs both return 404. Multiple visible documents with the same ID return 409. Metaconsole requires serverId; node rejects it. No ITSM lookup or mutation is performed.
