    GET /log/agent/list¶

    List agents with retained log entries

    Defaults to the last 24 hours. Uses event dates, not collection status. On a metaconsole, delegates to nodes. Continue in blocks using the same filters and returned cursor; no numbered pages, exact totals or immutable snapshot. Retention limits history. Query/body filters merge with body precedence.

    Parameters

    Name In Type Required Description

    from query string (date-time) Inclusive UTC-normalized event date; requires to, timezone and second precision
    to query string (date-time) Exclusive event date; requires from
    sizePage query integer

    GET /log/agent/{idAgent}/entry/list¶

    Read retained log entries of an authorized agent

    Defaults to last 24h by event date. Optional source is an exact literal match. Newest events first; backend index and document ID break equal-date ties. Cursor blocks, no numbered pages, exact totals or immutable snapshot. Repeat original filters and sizePage. The metaconsole delegates to the cached parent's node. Content is literal text, not safe HTML.
