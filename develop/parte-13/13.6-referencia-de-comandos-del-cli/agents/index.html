    agent¶

    Monitoring agents

    name is generated by the console: a sha256 unless aliasAsName=1, so alias is the value to show a human. Anything that addresses the agent by name (pushed monitoring data, the agent's own reports) must use name, not alias. The agent also needs a serverName matching the node, or the server never processes it.

    module¶

    Agent modules

    create needs a valid idModule and idModuleType pair: idModule is the module origin (1 for an agent module) and the type ids come from module-type list. Otherwise the API answers only "Unsupported module and module type combination", and idModule is read-only on update, so the pair must be right at create time. Pushed monitoring data needs an async type: a generic module stores the value but never computes a status.
