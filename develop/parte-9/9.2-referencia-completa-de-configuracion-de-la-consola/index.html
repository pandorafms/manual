    Referencia completa de configuración de la consola¶

    Esta referencia no se lee de corrido: se consulta por nombre de opción o por pestaña, como un diccionario. Reúne toda la configuración de la consola web (nodo y Command Center) y de include/config.php, para que cualquier otro capítulo pueda enlazar aquí en vez de repetir una tabla de opciones.

    Dónde vive cada cosa:

    • Consola web (Ajustes → Configuración del sistema). Casi toda la configuración de comportamiento, aspecto y credenciales de servicios externos. Se guarda en la base de datos, no en un fichero: cambia en caliente, sin reiniciar nada.
    • include/config.php. Un puñado de valores que solo se editan a mano, antes de que la consola pueda conectar con la base de datos: conexión a la base de datos, ruta de instalación, frase de cifrado. Ver § 23.
    • Command Center. Consola especial que centraliza varios nodos. Tiene sus propias páginas de configuración (§ 22) y, además, puede fijar centralizadamente ciertos ajustes de los nodos que gestiona.

    Un nodo con «Gestión centralizada» activa en una sección concreta deja de aceptar cambios locales en esa sección: se editan desde el Command Center y se sincronizan al nodo.

    22.3 Qué se sincroniza del nodo desde el Command Center¶

    La «gestión centralizada» permite que el Command Center escriba la configuración de un nodo, además de políticas, ACL avanzado y componentes, de forma sincronizada: la sección afectada del nodo deja de aceptar cambios locales mientras la gestión centralizada esté activa (ver introducción de este capítulo). El detalle exacto de qué secciones son sincronizables no está verificado a fecha de esta redacción; se ampliará en una revisión posterior de este capítulo.
