# Control remoto con RC

Monitorizar un equipo no es lo mismo que poder entrar en él. Pandora RC cubre esa segunda parte: tomar el control de una máquina Windows, Linux o macOS desde el navegador, sin depender de su dirección IP ni de abrir puertos en la red remota. La integración con Pandora FMS lleva ese control a la propia ficha del agente, de modo que el operador no tiene que saltar a otro portal ni copiar identificadores.

## Qué es y cuándo usarlo

Pandora RC, antes llamado eHorus, es un sistema de gestión remota. El equipo destino ejecuta un agente RC que mantiene una conexión saliente con el servicio de Pandora RC. Desde la consola de Pandora FMS se abre el cliente web de RC y se accede a ese equipo como si se estuviera delante de él.

La integración aporta tres cosas: el identificador del equipo queda asociado al agente de Pandora FMS, la pestaña **Pandora RC** aparece en su ficha y el cliente se lanza desde ahí. No sustituye a la monitorización ni a los módulos: es una vía de acceso para resolver lo que la monitorización detecta.

No confunda este capítulo con los vecinos. La distribución de software (3.3) instala o actualiza programas; la ejecución remota de scripts y comandos (3.4) lanza comandos; el control remoto con RC abre una sesión gráfica o de shell para operar en el equipo. Pandora RC es, además, un producto con licencia propia: el RC en modo SaaS va incluido con la licencia Pandora RMM y el RC on-premise se contrata aparte (ver [1.5](../parte-1/1.5-licenciamiento.md#pandora-rc)).

## Requisitos

| Requisito | Detalle |
|---|---|
| Agente RC | Instalado y provisionado en el equipo destino, con conexión al servicio de Pandora RC. |
| Usuario RC | Una cuenta de Pandora RC con acceso a ese agente. Si el usuario no lo ve, la sesión no se puede abrir. |
| Integración activada | La sección **Pandora RC** de la configuración de la consola debe estar activa y con credenciales válidas (ver [9.2](../parte-9/9.2-referencia-completa-de-configuracion-de-la-consola.md#7-pandora-rc), apartado 7). |
| Clave RC | El campo personalizado configurado para la clave RC, `eHorusID` por defecto, debe tener el identificador del agente RC. |
| Permisos | `AW` sobre el grupo del agente o ser administrador. Si la configuración por usuario está activa, el usuario necesita además sus credenciales RC habilitadas. |
| Consola | Salida HTTPS al servicio de Pandora RC. Si la consola se ejecuta en Windows, el almacén de certificados CA debe estar configurado en PHP. |
| Licencia | RC SaaS incluido con Pandora RMM; RC on-premise aparte (ver [1.5](../parte-1/1.5-licenciamiento.md#pandora-rc)). |

## La pestaña Pandora RC en el agente

La pestaña aparece en la barra superior de la vista del agente, junto al resto de pestañas. Se muestra cuando la integración está activa y el campo personalizado de la clave RC existe y tiene un valor. El icono es el de Pandora RC.

![Pestaña Pandora RC en la vista del agente, con el submenú de acciones](../../assets/img/parte-03/control-remoto-rc-pestana.png)

Al pasar el cursor por la pestaña se despliega un submenú con cinco acciones: **Terminal**, **Display**, **Processes**, **Services** y **Files**. Cada una abre el cliente de Pandora RC en la sección correspondiente. El resto de pestañas de la ficha del agente se explican en [2.21](../parte-2/2.21-configuracion-comun-de-los-agentes.md#las-pestanas-de-la-vista-del-agente).

Si la pestaña no aparece, el problema suele estar antes de la integración: falta el campo personalizado, el agente no tiene valor o la clave no se ha generado. Si aparece pero el submenú no se despliega, revise la integración y los permisos.

## Acciones disponibles

Las cinco acciones comparten el mismo flujo: se elige una, se pulsa **Launch** y se abre la sesión. Si el agente RC tiene contraseña local, se pide al conectar.

| Acción | Qué permite |
|---|---|
| **Terminal** | Abre una shell interactiva en el equipo remoto, con los permisos del agente RC. |
| **Display** | Muestra el escritorio remoto y permite interactuar con él. |
| **Processes** | Consulta los procesos del equipo y permite gestionarlos. |
| **Services** | Consulta y controla los servicios del sistema. |
| **Files** | Explora el sistema de archivos y transfiere ficheros. |

La barra flotante de **Display** permite minimizar la barra, hacer una captura de pantalla, usar el portapapeles remoto, enviar combinaciones de teclas como `Ctrl+Alt+Del` y pasar a pantalla completa. En **Terminal** conviene extremar las precauciones: se está trabajando con la misma cuenta que ejecuta el agente RC.

Pandora RC permite una sesión activa por equipo. Si otro usuario está conectado, el agente aparece ocupado y la sesión no se abre hasta que se libere. La sesión también se cierra por inactividad según el tiempo configurado en el agente RC, 300 segundos por defecto.

## Obtener la clave RC

La clave RC es el identificador único del agente de Pandora RC. Se guarda en un campo personalizado del agente de Pandora FMS. El nombre del campo se configura en la integración; el valor por defecto es `eHorusID`.

El EndPoint puede rellenarlo automáticamente. En el EndPoint Go y en el de Windows, la ruta del fichero de configuración del agente RC se indica con el token `prc_conf` o su alias `pandorarc_conf`. Si el fichero existe y contiene la clave, el EndPoint añade el campo personalizado con ese valor. El EndPoint Perl de Unix lee `ehorus_conf`, que se mantiene como alias heredado.

El EndPoint Go, si no se indica una ruta, prueba las ubicaciones estándar `/etc/pandorarc/pandorarc_agent.conf` y `/etc/ehorus/ehorus_agent.conf`. En Windows, la ruta la fija el instalador. La referencia completa de estos tokens y su compatibilidad por EndPoint está en [9.1](../parte-9/9.1-referencia-completa-de-configuracion-del-endpoint.md).

También se puede escribir la clave a mano en el campo personalizado del agente. Es la vía útil cuando el agente RC está en un equipo sin EndPoint propio o cuando la clave se obtiene por otro medio. En ambos casos, compruebe que el valor coincide con el del agente RC: si no coincide, la pestaña puede aparecer, pero la sesión no llegará al equipo correcto.

## Seguridad y límites

- **Contraseña local del agente RC.** Es opcional y se configura en el agente RC, no en Pandora FMS. No se almacena en los servidores centrales de RC; se pide de forma interactiva al conectar. Úsela si el equipo es sensible.
- **Credenciales de la API.** El usuario y la contraseña de Pandora RC se guardan cifrados en la base de datos de la consola (ver [9.5](../parte-9/9.5-cifrado-de-la-base-de-datos.md)). Si la configuración por usuario está activa, cada usuario usa las suyas.
- **HTTPS y certificados.** El cliente se conecta por HTTPS. Si la consola está en Windows y no reconoce la CA del servicio RC, configure `curl.cainfo` en `php.ini` con un almacén de certificados válido.
- **Una sesión por equipo.** RC no permite dos sesiones simultáneas sobre el mismo agente. Planifique el acceso o espere a que se libere.
- **Caducidad por inactividad.** La sesión se cierra sola pasado el tiempo configurado en el agente RC. Si se queda abierta y sin usar, el equipo queda bloqueado hasta que se cierre.
- **Licencia y modalidad.** RC SaaS y RC on-premise no son lo mismo. El primero va con Pandora RMM; el segundo se contrata aparte y requiere su propio despliegue. Ver [1.5](../parte-1/1.5-licenciamiento.md#pandora-rc).

## Problemas habituales

- **La pestaña no aparece.** Falta el campo personalizado, el agente no tiene valor o la integración no está configurada. Revise el campo `eHorusID` y la sección **Pandora RC** de la configuración.
- **Error de autenticación.** El usuario RC no tiene acceso a ese agente o las credenciales de la API no son válidas. Pruebe la conexión desde la configuración global ([9.2](../parte-9/9.2-referencia-completa-de-configuracion-de-la-consola.md#7-pandora-rc), apartado 7).
- **Error de conexión.** Revise el hostname y el puerto de la API, la salida HTTPS de la consola y, en Windows, el certificado CA.
- **El agente aparece ocupado.** Otro usuario tiene una sesión activa. Espere a que se libere.
- **El EndPoint no genera `eHorusID`.** Compruebe la ruta del token `prc_conf`/`pandorarc_conf` (o `ehorus_conf` en Perl) y que el fichero sea legible por el usuario del agente.
- **La sesión se abre pero no hay imagen o terminal.** El agente RC no está conectado al servicio RC, o hay un proxy o cortafuegos en medio. El diagnóstico de esa parte corresponde a la documentación de Pandora RC.
