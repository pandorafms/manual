# Référence complète de configuration du serveur

> Référence technique brute de `pandora_server.conf` : tous les jetons que
> reconnaît le serveur, avec leur valeur par défaut réelle. Elle se consulte,
> elle ne se lit pas d'un bout à l'autre ; tout autre chapitre renvoie ici
> quand il doit se référer à un paramètre du serveur.

## Introduction

`pandora_server.conf` est l'unique fichier de configuration du serveur
Pandora FMS. Son chemin est configurable à l'installation ; par défaut,
`/etc/pandora/pandora_server.conf`. Le format est celui de la maison : un jeton
par ligne, la valeur après un espace, et `#` pour commenter une ligne entière ou
pour laisser un jeton d'exemple désactivé.

Une modification du fichier ne s'applique pas à chaud : il faut redémarrer le
service.

```sh
systemctl restart pandora_server
```

L'exception est la configuration distante : avec `remote_config 1` (voir
« Configuration distante, Tentacle et synchronisation », plus bas), le fichier
entier peut être modifié depuis la console web. Le serveur vérifie
régulièrement s'il y a des changements ; quand il en trouve, il génère un
événement de redémarrage, recharge la configuration et redémarre de lui-même.

Les jetons propres aux serveurs satellite (`pandora_satellite.conf`) ne
figurent pas dans cette référence : ils ont leur propre chapitre,
[6.2 · Serveurs satellite](../parte-6/6.2-servidores-satelite.md), qui renvoie
ici pour ce qu'ils partagent avec le serveur principal.

La « valeur par défaut » de chaque table est celle que le serveur applique
lui-même quand le jeton n'apparaît pas dans le fichier. Le modèle d'exemple
fourni avec le paquet (`pandora_server.conf.new`) ne coïncide pas toujours avec
cette valeur : quand il en diffère de façon significative, la table l'indique
explicitement, jamais comme s'il s'agissait de « la » valeur par défaut.

## 2. Activation des serveurs et nombre de threads

Chaque serveur interne a un interrupteur (`0`/`1`) et, le cas échéant, un nombre
de threads propre. « Par défaut » est, comme dans le reste de ce chapitre, la
valeur que le serveur assume lui-même quand le jeton n'apparaît pas dans le
fichier ; le modèle de l'installation (`pandora_server.conf.new`) peut apporter
une valeur différente pour ce même jeton. Par exemple, `discoveryserver` est
activé dans le modèle alors que la valeur interne par défaut est `0`, et
inversement, `snmpconsole` est désactivé dans le modèle alors que la valeur
interne par défaut est `1`.

| Serveur | Jeton d'activation | Par défaut | Jeton de threads | Par défaut |
|---|---|---|---|---|
| Données (XML) | `dataserver` | `1` | `dataserver_threads` | `2` |
| Réseau (TCP, commandes distantes, WMI ; ICMP et SNMP si celui à hautes performances est désactivé) | `networkserver` | `1` | `network_threads` | `3` |
| Réseau à hautes performances (ICMP avec `fping` et SNMP avec `pandorafsnmp`, par lots) | `networkhpserver` | `1` | `networkhpserver_threads` | `4` |

Elle est utilisée lorsque le fichier définit `mta_address` (voir `mta_local`) ; si la configuration du courrier vient de la console, c'est l'option **Authentification SMTP** de [9.2 · Référence complète de configuration de la console](9.2-referencia-completa-de-configuracion-de-la-consola.md) § 1.7 qui la fixe. Le serveur utilise le premier des mécanismes de la liste annoncé par le serveur de courrier, sans réessayer avec le suivant. | `none` |
| `mta_encryption` | Chiffrement de la connexion SMTP (`none`, `ssl`, `starttls`). | `none` |
| `mta_from` | Expéditeur des courriels d'alerte. | `pandora@localhost` |
| `mta_local` | Indicateur dérivé : l'analyseur le passe à `1` dès que `mta_address` apparaît, et il fait prévaloir tout le bloc `mta_*` de ce fichier sur la configuration du courrier de la console. Il ne s'écrit pas à la main. | `0` |
| `mail_in_separate` | Envoie un courriel par destinataire au lieu d'un seul partagé. | `1` |
| `mail_subject_encoding` | Encodage de l'objet du courriel. | `MIME-Header` |

Le délai d'attente de la connexion SMTP n'est pas un jeton de ce fichier : il se
configure dans la console (§ 1.7 de 9.2) et sa valeur par défaut est de 10 s.
