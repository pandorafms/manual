    Référence complète de configuration du serveur¶

    Référence technique brute de pandora_server.conf : tous les jetons que reconnaît le serveur, avec leur valeur par défaut réelle. Elle se consulte, elle ne se lit pas d'un bout à l'autre ; tout autre chapitre renvoie ici quand il doit se référer à un paramètre du serveur.

    Introduction¶

    pandora_server.conf est l'unique fichier de configuration du serveur Pandora FMS. Son chemin est configurable à l'installation ; par défaut, /etc/pandora/pandora_server.conf. Le format est celui de la maison : un jeton par ligne, la valeur après un espace, et # pour commenter une ligne entière ou pour laisser un jeton d'exemple désactivé.

    Une modification du fichier ne s'applique pas à chaud : il faut redémarrer le service.

    systemctl restart pandora_server

    L'exception est la configuration distante : avec remote_config 1 (voir « Configuration distante, Tentacle et synchronisation », plus bas), le fichier entier peut être modifié depuis la console web. Le serveur vérifie régulièrement s'il y a des changements ; quand il en trouve, il génère un événement de redémarrage, recharge la configuration et redémarre de lui-même.

    Les jetons propres aux serveurs satellite (pandora_satellite.conf) ne figurent pas dans cette référence : ils ont leur propre chapitre, 6.2 · Serveurs satellite, qui renvoie ici pour ce qu'ils partagent avec le serveur principal.

    La « valeur par défaut » de chaque table est celle que le serveur applique lui-même quand le jeton n'apparaît pas dans le fichier. Le modèle d'exemple fourni avec le paquet (pandora_server.conf.new) ne coïncide pas toujours avec cette valeur : quand il en diffère de façon significative, la table l'indique explicitement, jamais comme s'il s'agissait de « la » valeur par défaut.

    2. Activation des serveurs et nombre de threads¶

    Chaque serveur interne a un interrupteur (0/1) et, le cas échéant, un nombre de threads propre. « Par défaut » est, comme dans le reste de ce chapitre, la valeur que le serveur assume lui-même quand le jeton n'apparaît pas dans le fichier ; le modèle de l'installation (pandora_server.conf.new) peut apporter une valeur différente pour ce même jeton. Par exemple, discoveryserver est activé dans le modèle alors que la valeur interne par défaut est 0, et inversement, snmpconsole est désactivé dans le modèle alors que la valeur interne par défaut est 1.

    Serveur Jeton d'activation Par défaut Jeton de threads Par défaut
    Données (XML) dataserver 1 dataserver_threads 2
    Réseau (TCP, commandes distantes, WMI ; ICMP et SNMP si celui à hautes performances est désactivé) networkserver 1 network_threads 3
    Réseau à hautes performances (ICMP avec fping et SNMP avec pandorafsnmp, par lots) networkhpserver 1 networkhpserver_threads 4
    Console SNMP snmpconsole 1 snmpconsole_threads 1
    SNMP (hérité : ne démarre plus de serveur propre ; active seulement la vérification que snmptrapd continue de recevoir des traps) snmpserver 0 snmp_threads 3
    ICMP (hérité : sans effet ; l'exécute le serveur réseau à hautes performances) icmpserver 0 icmp_threads 3
    WMI (hérité : sans effet ; l'exécute le serveur réseau) wmiserver 1 wmi_threads 2
    Plugin (hérité : sans effet ; l'exécute le serveur Heavy) pluginserver 1 plugin_threads 2
    Discovery discoveryserver 0 discovery_threads 2
    Prédiction (hérité : sans effet ; l'exécute le serveur réseau) predictionserver 1 prediction_threads 1

    console_api_pass Mot de passe de l'API de la console, pour les intégrations du serveur avec la console. sans valeur
    console_user / console_pass Identifiants de console utilisés par certaines intégrations du serveur. sans valeur
    checksum Vérification d'intégrité à usage interne. sans valeur par défaut documentée

    Voir 9.5 · Chiffrement de la base de données pour la procédure complète d'activation et de gestion du chiffrement.

    13. Command Center¶

    pandora_server.conf n'a pas de bloc de jetons propre au Command Center : la relation entre un serveur et le Command Center se gère au niveau de la console (enregistrement du nœud, synchronisation des politiques) et de la base de données, pas dans le fichier de configuration du serveur.

    Jeton Ce qu'il fait Valeur par défaut
    node_metaconsole Indique si la base de données vers laquelle pointe ce serveur est celle d'un nœud géré par un Command Center. Ce n'est pas une option à modifier à la main dans le fichier. 0

    Voir 6.3 · Command Center pour la procédure d'enregistrement et de gestion des nœuds.
