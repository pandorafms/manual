    Référence complète de configuration de la console¶

    Cette référence ne se lit pas d'un bout à l'autre : on la consulte par nom d'option ou par onglet, comme un dictionnaire. Elle réunit toute la configuration de la console web (nœud et Command Center) et de include/config.php, afin que tout autre chapitre puisse renvoyer ici au lieu de répéter une table d'options.

    Où se trouve chaque élément :

    • Console web (Réglages → Configuration du système). Presque toute la configuration de comportement, d'apparence et d'identifiants de services externes. Elle est enregistrée dans la base de données, pas dans un fichier : elle change à chaud, sans redémarrer quoi que ce soit.
    • include/config.php. Une poignée de valeurs qui ne se modifient qu'à la main, avant que la console puisse se connecter à la base de données : connexion à la base de données, chemin d'installation, phrase de chiffrement. Voir § 23.
    • Command Center. Console spéciale qui centralise plusieurs nœuds. Elle a ses propres pages de configuration (§ 22) et peut, en plus, fixer de façon centralisée certains réglages des nœuds qu'elle gère.

    Un nœud dont la « Gestion centralisée » est active dans une section donnée cesse d'accepter des changements locaux dans cette section : ils se modifient depuis le Command Center et se synchronisent vers le nœud.
