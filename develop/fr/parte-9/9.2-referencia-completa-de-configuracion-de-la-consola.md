# Référence complète de configuration de la console

Cette référence ne se lit pas d'un bout à l'autre : on la consulte par nom
d'option ou par onglet, comme un dictionnaire. Elle réunit toute la configuration
de la console web (nœud et Command Center) et de `include/config.php`, afin que
tout autre chapitre puisse renvoyer ici au lieu de répéter une table d'options.

Où se trouve chaque élément :

- **Console web (Réglages → Configuration du système).** Presque toute la
  configuration de comportement, d'apparence et d'identifiants de services
  externes. Elle est enregistrée dans la base de données, pas dans un fichier :
  elle change à chaud, sans redémarrer quoi que ce soit.
- **`include/config.php`.** Une poignée de valeurs qui ne se modifient qu'à la
  main, avant que la console puisse se connecter à la base de données : connexion
  à la base de données, chemin d'installation, phrase de chiffrement. Voir § 23.
- **Command Center.** Console spéciale qui centralise plusieurs nœuds. Elle a ses
  propres pages de configuration (§ 22) et peut, en plus, fixer de façon
  centralisée certains réglages des nœuds qu'elle gère.

Un nœud dont la « Gestion centralisée » est active dans une section donnée cesse
d'accepter des changements locaux dans cette section : ils se modifient depuis le
Command Center et se synchronisent vers le nœud.

| Adresse et nom d'origine | Expéditeur des courriels | Vide |  |
| Jeton de Telegram | Remplace la macro d'alerte qui référence le jeton du bot | Vide |  |

L'option **Authentification SMTP** n'essaie pas les mécanismes l'un après
l'autre. Le serveur de Pandora FMS utilise le premier annoncé par le serveur
de courrier et, s'il le refuse, l'envoi échoue. Un fournisseur qui annonce
`DIGEST-MD5` puis le refuse — Postmark est le cas à l'origine de ce réglage —
oblige à choisir `LOGIN` à la main. `PLAIN` est exclu de la valeur par défaut
car certains serveurs répondent avec l'erreur `451 4.5.0 SMTP protocol
violation`. L'option ne s'applique que lorsque le courrier est configuré dans
la console ; si `pandora_server.conf` définit `mta_address`, les valeurs
`mta_*` du fichier l'emportent et ce réglage n'intervient pas.

### 1.8 Update

Formulaire de courriel de test (Email test) pour valider la configuration de
l'onglet précédent sans quitter la page ; ce n'est pas une option de
configuration. L'envoi est fait par la console, pas par le serveur, et
n'utilise pas le mécanisme d'authentification SMTP du § 1.7 : un test réussi ne
garantit pas que les alertes partiront.

serveur](9.3-referencia-completa-de-configuracion-del-servidor.md) § 11, pour le
courriel sortant que le serveur lui-même utilise à l'exécution des alertes.

| `$config['dbsslcafile']` | Chemin du certificat CA pour SSL | Vide |
| `$config['sslverifyservercert']` | Vérifie le certificat du serveur de base de données | `1` |

La phrase dont dérive la clé de chiffrement de la base de données
(`encryption_passphrase`) **ne** vit **pas** dans `config.php`, mais dans la table
de configuration elle-même : elle se gère depuis la console web. Elle n'est
mentionnée ici que pour que cette référence soit complète. Voir [9.5 ·
Chiffrement de la base de données](9.5-cifrado-de-la-base-de-datos.md).
