# Référence complète de configuration de l'EndPoint

> Référence technique brute de `pandora_agent.conf` : tous les jetons généraux
> et tous les jetons de module, avec leur compatibilité par EndPoint (Go,
> Perl, Windows). Elle se consulte, elle ne se lit pas d'un bout à l'autre. Les
> explications et les exemples se trouvent dans
> [2.1 · Supervision avec des EndPoints](../parte-2/2.1-monitorizacion-con-endpoints.md),
> vers laquelle cette page renvoie.

## Introduction

Cette référence rassemble, table par table, tous les jetons de
`pandora_agent.conf` reconnus par les trois EndPoints de Pandora FMS : l'EndPoint
Go, l'EndPoint Perl (Linux/Unix) et l'EndPoint Windows. Pour chaque jeton, elle
indique sa description, sa syntaxe ou valeur par défaut, et si l'EndPoint Go,
l'EndPoint Perl et l'EndPoint Windows l'acceptent.

`pandora_agent.conf` se trouve dans :

| EndPoint | Chemin |
|---|---|
| Go et Perl (Linux/Unix) | `/etc/pandora/pandora_agent.conf`. Les deux utilisent le même fichier au même chemin. Avec une installation dans un chemin propre, la configuration reste dans `<prefix>/etc/pandora/` ; sur FreeBSD et NetBSD, l'installeur utilise déjà `/usr/local/etc/pandora`. |
| Windows | `C:\Program Files\pandora_agent\pandora_agent.conf` |

La syntaxe du fichier est la même dans les trois EndPoints : un jeton par ligne,
des commentaires avec `#`, et les jetons de module regroupés en blocs
`module_begin` / `module_end` (sauf `module_plugin`, qui peut aussi aller seul
sur une ligne, hors de tout bloc). Les jetons généraux sont valables à n'importe
quelle position du fichier, hors d'un bloc de module.

Pour les explications, les exemples et le pourquoi de chaque jeton, voir
[2.1 · Supervision avec des EndPoints](../parte-2/2.1-monitorizacion-con-endpoints.md).

| Jeton | Description | Valeur / défaut | Go | Perl | Windows |
|---|---|---|---|---|---|

## Différences notables entre les EndPoints

- **Encodage du XML par défaut.** Perl et Go utilisent `UTF-8` ; Windows utilise
  `ISO-8859-1` (voir `encoding`).
- **Nom différent pour un même concept.** Le délai de démarrage s'appelle
  `delayed_startup` en Perl et Go, et `startup_delay` sous Windows.
- **Alias de jeton.** `module_service` est un alias exact de `module_proc` sous
  Unix (même vérification de processus) ; sous Windows, ce sont des builtins
  distincts (processus vs. service), avec des watchdogs au comportement
  différent.
- **Watchdog asymétrique.** Le watchdog de Windows n'existe que pour
  `module_proc` (il a besoin de `module_start_command`, `module_retries`,
  `module_startdelay`, `module_retrydelay`, `module_user_session`) et pour
  `module_service` (il redémarre le service lui-même, sans commande de
  récupération). Ni Perl ni Go n'implémentent de watchdog.
- **Module asynchrone sous Windows seulement.** `module_async` n'existe que dans
  l'EndPoint Windows ; Perl et Go dérivent le type asynchrone automatiquement
  quand un module avec `module_absoluteinterval` s'exécute `once`.
- **Jetons à nom variable.** `module_macro<nom>` (macros de module)
  et `custom_field<n>_name` / `custom_field<n>_value` sont admis par les trois
  EndPoints ; les macros générales `macro<nom>`, seulement par Perl et Go.
- **Serveur UDP.** Il n'existe qu'en Perl et sous Windows (pas en Go). Le format
  des ordres diffère : Perl accepte `START PROCESS <nom>` /
  `STOP PROCESS <nom>` ; Windows exige exactement trois mots
  (`<ordre> <action> <cible>`, par ex. `REFRESH AGENT *`,
  `START PROCESS <nom>`, `START SERVICE <nom>`), et il ajoute le contrôle des
  services (`service_<nom>`) que Perl n'a pas.
- **Configuration distante et transport.** L'EndPoint Go n'admet
  `remote_config` qu'avec `transfer_mode` `tentacle` ou `local` ; Perl l'admet
  avec n'importe quel mode de transfert.
- **Jetons exclusifs à Windows.** Tous les modules intégrés d'interrogation de
  Windows (`module_wmiquery`, `module_perfcounter`, `module_snmpget`,
  `module_ping`, `module_tcpcheck`, `module_logevent`/`module_logchannel` et
  leurs filtres, `module_inventory`, `module_exec_powershell`), en plus de
  `disable_logfile`, `default_native_encoding`, `startup_delay` et
  `udp_server_address`.
- **Jetons exclusifs à Unix (Perl et Go).** `module_cpuproc`,
  `module_memproc`, `module_occupiedpercentdisk`, `module_proc_cmd`,
  `module_freedisk_cmd`, `pandora_user`, `logfile`/`logsize`/`logrotate`,
  `cron_mode`, `agent_threads`, `cmd_file`, `include`, `timezone_offset`,
  `pandora_nice`, `transfer_mode_user` et `server_path_conf` /
  `server_path_md5` / `server_path_zip`.
- **Jeton seulement analysé, sans équivalent dans les deux autres.**
  `server_path_ref` n'existe que dans l'EndPoint Perl (répertoire de référence
  de la configuration distante).
