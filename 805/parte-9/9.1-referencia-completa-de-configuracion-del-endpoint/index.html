    Referencia completa de configuración del EndPoint¶

    Referencia técnica en bruto de pandora_agent.conf: todos los tokens generales y todos los tokens de módulo, con su compatibilidad por EndPoint (Go, Perl, Windows). Se consulta, no se lee de corrido. Las explicaciones y los ejemplos están en 2.1 · Monitorización con EndPoints, a la que se enlaza.

    Introducción¶

    Esta referencia recoge, tabla a tabla, todos los tokens de pandora_agent.conf reconocidos por los tres EndPoints de Pandora FMS: el EndPoint Go, el EndPoint Perl (Linux/Unix) y el EndPoint Windows. Para cada token se indica su descripción, su sintaxis o valor por defecto, y si el EndPoint Go, el EndPoint Perl y el EndPoint Windows lo admiten.

    pandora_agent.conf se ubica en:

    EndPoint Ruta
    Go y Perl (Linux/Unix) /etc/pandora/pandora_agent.conf. Los dos usan el mismo fichero en la misma ruta. Con una instalación en una ruta propia, la configuración queda en <prefijo>/etc/pandora/; en FreeBSD y NetBSD, el instalador ya usa /usr/local/etc/pandora.
    Windows C:\Program Files\pandora_agent\pandora_agent.conf

    La sintaxis del fichero es la misma en los tres EndPoints: un token por línea, comentarios con #, y los tokens de módulo agrupados en bloques module_begin / module_end (salvo module_plugin, que también puede ir suelto en una única línea, fuera de cualquier bloque). Los tokens generales son válidos en cualquier posición del fichero, fuera de un bloque de módulo.

    Para explicaciones, ejemplos y el porqué de cada token, ver 2.1 · Monitorización con EndPoints.

    Estructura del módulo¶

    Token Descripción Valor / por defecto Go Perl Windows

    module_type Tipo de dato del módulo (numérico, incremental, cadena, proc, log, versión asíncrona…), define cómo lo interpreta el servidor. Texto (p. ej. generic_data, generic_data_string, generic_proc, async_data…). Por defecto generic_data. Sí Sí Sí

    Diferencias notables entre EndPoints¶

    • Codificación del XML por defecto. Perl y Go usan UTF-8; Windows usa ISO-8859-1 (ver encoding).
    • Nombre distinto para el mismo concepto. El retardo de arranque se llama delayed_startup en Perl y Go, y startup_delay en Windows.
    • Alias de token. module_service es un alias exacto de module_proc en Unix (misma comprobación de proceso); en Windows son builtins distintos (proceso vs. servicio), con watchdogs de comportamiento distinto.
    • Watchdog asimétrico. El watchdog de Windows solo existe para module_proc (necesita module_start_command, module_retries, module_startdelay, module_retrydelay, module_user_session) y para module_service (reinicia el propio servicio, sin comando de recuperación). Ni Perl ni Go implementan watchdog.
    • Módulo asíncrono solo en Windows. module_async únicamente existe en el EndPoint Windows; Perl y Go derivan el tipo asíncrono automáticamente cuando un módulo con module_absoluteinterval se ejecuta once.
    • Tokens con nombre variable. module_macro<nombre> (macros de módulo) y custom_field<n>_name / custom_field<n>_value los admiten los tres EndPoints; las macros generales macro<nombre>, solo Perl y Go.
    • Servidor UDP. Solo existe en Perl y Windows (no en Go). El formato de las órdenes difiere: Perl acepta START PROCESS <nombre> / STOP PROCESS <nombre>; Windows exige exactamente tres palabras (<orden> <acción> <objetivo>, p. ej. REFRESH AGENT *, START PROCESS <nombre>, START SERVICE <nombre>), y añade el control de servicios (service_<nombre>) que Perl no tiene.
    • Configuración remota y transporte. El EndPoint Go solo admite remote_config con transfer_mode tentacle o local; Perl la admite con cualquier modo de transferencia.
    • Tokens exclusivos de Windows. Todos los módulos integrados de consulta a Windows (module_wmiquery, module_perfcounter, module_snmpget, module_ping, module_tcpcheck, module_logevent/module_logchannel y sus filtros, module_inventory, module_exec_powershell), además de disable_logfile, default_native_encoding, startup_delay y udp_server_address.
    • Tokens exclusivos de Unix (Perl y Go). module_cpuproc, module_memproc, module_occupiedpercentdisk, module_proc_cmd, module_freedisk_cmd, pandora_user, logfile/logsize/logrotate, cron_mode, agent_threads, cmd_file, include, timezone_offset, pandora_nice, transfer_mode_user y server_path_conf / server_path_md5 / server_path_zip.
    • Token solo parseado, sin equivalente en los otros dos. server_path_ref solo existe en el EndPoint Perl (directorio de referencia de la configuración remota).
